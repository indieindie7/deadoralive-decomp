Sega Saturn game Dead or Alive (Tecmo, Japan Rev A T-3603G V1.002, 1997; SH-2 code, Hitachi SHC or GNU; SGL/SBL library calls likely). Research only. Game: 3D one-on-one fighting game (port of the Model 2 arcade): 10+ fighters (Kasumi KS, Leon LE, Tina TN, Lei Fang LU, Zack ZA, Bayman BY, Gen Fu GE, Jann Lee, Ryu Hayabusa RI, Raidou), strikes, throws, the counter-hold system (hold vs high/mid/low strike, timing windows), danger zone ring edges that launch fighters, juggles, KO and round flow, motion data per fighter (XX_DAT.BIN), textures/models (XXn_TEX/MDL/LAD/TNK.BIN), VDP1 polygons, VDP2 backgrounds, CPK/AVI movies, sound through the 68000 driver. Main program 00DOA.BIN is loaded at 0x06004000. Focus names on the main loop and mode dispatch, file loader, input buffer and command parser, move/motion playback, hit detection (hit/hurt spheres), damage, counter-hold checks, danger zone, AI, camera, 3D transform and polygon output, menus, sound commands.

Task: name functions from the Ghidra decompile. FILE holds the decompile of a slice of the functions of 00DOA.BIN. Name EVERY function in FILE whose name is still FUN_xxxxxxxx (skip ones that already have a name).

Evidence to use: strings, called functions (names given by earlier slices), Saturn hardware registers, how the function uses its arguments.
